# Message pour Madame Roussel : ticket 7 (le message de la carte coupé)

Bonjour Madame Roussel,

Merci de m'avoir signalé ce problème. Le site limitait le message de la carte à 150 caractères et, au-delà, il arrêtait simplement l'écriture, sans rien dire. Votre cliente s'est donc retrouvée bloquée au milieu de sa phrase, sans comprendre pourquoi.

Comme vous le souhaitez, j'ai supprimé cette limite : vos clientes peuvent maintenant écrire un message aussi long qu'elles veulent. J'ai vérifié avec un texte de plus de 150 caractères : il s'affiche en entier et il est bien conservé quand le bouquet est ajouté au panier.

Deux remarques, pour que vous décidiez en connaissance de cause :
- Si vous préférez garder une limite, plus large, avec un petit compteur qui indique combien de caractères il reste, je peux le mettre en place. La cliente saurait alors où elle en est.
- Dans le panier, la carte est indiquée (« Petit, carte »), mais le texte du message n'y apparaît pas. Si vous souhaitez que la cliente puisse le relire avant de commander, dites-le-moi.

Bien cordialement,
