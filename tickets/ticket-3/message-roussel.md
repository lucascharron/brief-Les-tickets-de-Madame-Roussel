# Message pour Madame Roussel : ticket 3 (un bouquet absent de l'occasion « Merci »)

Bonjour Madame Roussel,

Merci de m'avoir signalé ce problème. J'ai trouvé l'origine : dans la fiche du bouquet « Le petit mot », le mot « Merci » était écrit avec une majuscule, alors que le site cherche le mot « merci » écrit en minuscules. Le site ne faisait donc pas le lien entre ce bouquet et l'occasion « Merci », alors qu'il l'affichait bien dans la liste complète et dans « Pour le plaisir ».

C'est corrigé : « Le petit mot » apparaît maintenant quand on choisit l'occasion « Merci », avec les trois autres bouquets. J'ai vérifié les autres occasions (elles n'ont pas changé) et le reste de la boutique.

Bien cordialement,
