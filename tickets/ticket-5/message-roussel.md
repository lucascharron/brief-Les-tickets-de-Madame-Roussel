# Message pour Madame Roussel : ticket 5 (un bouquet supprimé, tout le panier vidé)

Bonjour Madame Roussel,

Merci de m'avoir signalé ce problème, et je suis désolé que cette cliente soit partie sans commander. J'ai trouvé l'origine : quand on cliquait sur « Supprimer » à côté d'un bouquet, le site retirait ce bouquet et aussi tous ceux qui étaient en dessous dans la liste. Supprimer le premier bouquet d'un panier de trois les faisait donc tous disparaître.

C'est corrigé : « Supprimer » retire maintenant uniquement le bouquet concerné. J'ai vérifié avec trois bouquets en supprimant le premier, le deuxième, puis le dernier, ainsi que le bouton « − » quand il ne reste qu'un exemplaire. Les autres fonctions de la boutique (codes promo, boutons + et −, occasions, tailles) fonctionnent toujours.

Si vous le souhaitez, vous pouvez recontacter cette cliente pour lui dire que le problème est réglé.

Bien cordialement,
