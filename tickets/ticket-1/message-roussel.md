# Message pour Madame Roussel : ticket 1 (le code promo refusé)

Bonjour Madame Roussel,

Merci de m'avoir signalé ce problème. J'ai trouvé l'origine : le site ne reconnaissait le code NOEL10 que s'il était écrit exactement en majuscules, sans espace avant ni après. Sur un téléphone, le clavier met souvent une majuscule au début d'un mot ou laisse un espace à la fin, et le code était alors refusé.

C'est corrigé : le code NOEL10 est maintenant accepté quelle que soit la façon de l'écrire (majuscules, minuscules, avec ou sans espace). J'ai vérifié sur le site que la réduction s'applique bien et qu'elle reste en place si la page est rechargée. Je n'ai pas pu essayer sur un téléphone, mais le correctif porte sur ce point précis. Un test de votre côté sur un mobile confirmerait que tout fonctionne comme prévu.

Je vous laisse décider de la suite à donner à la cliente qui a commandé sans la réduction.

Bien cordialement,
